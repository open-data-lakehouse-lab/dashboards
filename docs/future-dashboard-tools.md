# Future Dashboard Tools

While we start with static HTML, richer dashboarding and BI tools may be evaluated as the project matures.

## Possible Categories for Evaluation

- **BI Tools**: Open-source BI platforms for complex reporting and data exploration.
- **Operational Dashboards**: Real-time monitoring and alerting tools.
- **Web Frontends**: Custom-built web applications for specific user workflows.
- **Notebook-based Exploration**: Using Jupyter or similar for data science and deep dives.
- **Embedded Dashboards**: Components that can be integrated into other applications.

No final choice has been made, and the current static HTML generation remains the primary method for local foundation visualization.
