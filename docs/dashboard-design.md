# Dashboard Design

## Local-First Generation

The dashboards are generated locally from observability reports. This approach ensures that we can quickly visualize workflow results without setting up a database or a web server.

## Input: Observability Reports

The primary input is the `run-observability-report.json` generated by the observability repository. These reports contain metadata, metrics, health status, and details about failed steps.

## Output: Static HTML

The output is a standalone HTML document. 

- **Independent**: No external CSS, JS, or images are loaded.
- **Portable**: Can be opened in any modern web browser directly from the file system.
- **Secure**: All data is escaped to prevent HTML injection.

## Integration

In the future, dashboard generation will be integrated into the main orchestration flow, automatically creating a report after each workflow execution.
